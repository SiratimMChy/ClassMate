# 📘 CLASSMATE  
### Web-Based Academic Collaboration Platform

---

## 🧠 Project Overview

**CLASSMATE** is a web-based academic management system developed as part of a **4th-year defense project** at **Leading University**.  

University students often struggle with juggling multiple platforms for managing schedules, accessing learning materials, coding, and communication. ClassMate centralizes these academic and extracurricular activities into a single platform, allowing students to:  

- Access **lecture recordings**  
- Explore a **question bank** of past exams  
- Generate **formatted report cover pages**  
- Calculate **academic performance (CGPA)**  
- Interact with an **intelligent chatbot** for guidance  
- Run programs using an **online compiler**  
- Submit **makeup exam and permission requests**  
- Participate in **club registration and management**

By integrating these functionalities, ClassMate reduces dependency on multiple scattered resources, improves productivity, and enhances the overall student experience.

1. **Requirement Gathering & Feature Analysis**
